# Elo Lab Implementation Plan

**Goal:** Add a detailed Swedish research-style rating analysis page to KingPing using actual season history.

**Architecture:** Reuse the existing crown rating engine for chronological snapshots in both models, including historical AFK handling. A server page reads season-scoped data; a client report offers model, player, and time-axis controls with responsive SVG charts. Ratings reset within each selected season, matching the leaderboard.

**Tech Stack:** Next.js 15, React 19, TypeScript, Prisma, SVG, Vitest. No additional chart dependencies.

### 1. Rating history and statistics
- Test exact parity with the existing rating tables, chronology, full standings, AFK, unobserved players, zero-change participation, and empty data.
- Add an optional snapshot observer to the shared engine, avoiding duplicated Elo formulas or quadratic replay.
- Derive observed-player statistics: rating, peak, drawdown, latest five rated-round momentum, sample standard deviation of changes, and model difference.

### 2. Report route and visualizations
- Create `/elo` using `resolveSeason`, `listSeasons`, `winOccurredAtFilter`, and player AFK periods.
- Build trajectory, change heatmap, momentum/volatility scatter, expected-score matrix, model comparison bars, and sortable statistics.
- Add per-round inspection, selectable players, models and calendar/round axes, CSV export, real empty states, and an explicit methodology.
- Use Swedish copy, theme-compatible dark panels and distinct chart colors; include accessible labels, keyboard controls and horizontal overflow for dense views.
- Add the page to the global navigation and link from the leaderboard.

### 3. Verification
- Run the focused domain tests, complete Vitest suite, and TypeScript checking.
- Run a production compile without migration side effects.
- Inspect the live report in a browser when local database access is available; verify controls and narrow layout.

**Design choice:** Default to the current season with an archive selector. Full placement rating and classic crown rating are alternatives in the same report. Interpretations are descriptive, never statistical significance claims or forecasts. Unknown participation must not appear as a loss, zero volatility, or fabricated match history.
